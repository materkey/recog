# Versions of Recog's dependencies verified on macOS (Apple Silicon, Python
# 3.12). setup.sh passes this file as `pip install -c` on every darwin pip
# stage, and macOS CI uses the same file, so porting the project to Linux
# cannot drag the working Mac's ML stack to a new version as a side effect.
#
# Scope: Recog's own dependencies, direct and the transitive ones that carry
# ABI or model-behaviour risk. Deliberately NOT a freeze of the whole shared
# venv — packages unrelated to Recog (pyannote, optuna, playwright, ...) are
# out of scope, and pip is left to resolve the small pure-Python leaves.
#
# onnxruntime is deliberately absent: the pinned GigaAM constrains it itself,
# and the version installed in the reference venv predates that pin.
#
# Changing anything here is its own change with its own verification (RAM and
# latency on MPS are what these versions are pinned for) — do not bump a line
# as a side effect of another task, and never drop the constraints file to
# make an install resolve.
