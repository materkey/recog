# Настольный Толк

Recog может подключить своё расширение к уже работающему официальному приложению Толк на macOS или Linux. Приложение и его пакет не изменяются, поэтому обычные обновления Толка остаются доступными. Подключение выполняет наблюдатель внутри web-сервера Recog; отдельный постоянный сервис не нужен. Для передачи событий используется локальный bridge на loopback-интерфейсе.

Сначала установите Recog по [основной инструкции](../README.md) и соберите расширение:

```bash
cd browser-extension
npm install
npm run build
cd ..
```

Затем из корня репозитория включите автоподключение, указав установленное приложение:

```bash
bin/recog desktop enable --app /Applications/Толк.app
# Linux: bin/recog desktop enable --app ~/Applications/ktalk.AppImage
bin/recog desktop status --json
```

Укажите путь именно к той копии приложения, которую запускаете. Если Толк установлен в `~/Applications`, используйте этот путь. При переносе приложения или переключении между копиями повторите `desktop enable --app` с новым путём: наблюдатель привязан к выбранному приложению.

Web-сервер Recog должен работать, чтобы наблюдатель обнаружил следующий запуск Толка и подключился. Если Толк уже запущен, можно выполнить `bin/recog desktop attach`. Команда ожидает ровно один основной процесс выбранного приложения. Состояние также видно в настройках Recog; `status --json` показывает, в частности, `state`, `reason` и `inspector_closed`. `server_offline` означает, что web-сервер не работает.

Чтобы прекратить автоподключение новых процессов, выполните `bin/recog desktop disable`. Уже внедрённое расширение продолжит работать до выхода из Толка. Настройки и снимок собранного расширения хранятся в `<RECOG_DATA_DIR>/desktop/`, обычно `~/.recog/desktop/`; переменные окружения для этой функции редактировать не требуется. При повторной установке можно использовать `cargo setup --no-env`, чтобы не создавать файлы окружения из примеров.

Для краткого подключения Recog открывает локальный Node inspector процесса Толка и закрывает его после внедрения. Если состояние `inspector_unclosed`, закрытие не подтверждено: Recog сохраняет это состояние даже после `disable`, пытается восстановить закрытие и не начинает новое подключение, пока проблема не разрешена. После встречи вручную перезапустите Толк и проверьте `status --json`. Inspector на loopback доступен другим процессам того же пользователя, пока открыт; не запускайте недоверенный код под этой учётной записью во время подключения.

Recog проверяет выбранный процесс и локальный пакет приложения, но это не подтверждение подлинности от поставщика. Совместимость с каждой будущей версией Толка не гарантирована; при `incompatible` проверьте состояние и обновление Recog. Настройка провайдера и модели Copilot выполняется отдельно.

Перед сигналом загрузчик читает флаги Electron без изменения бинарника. Если поддержка inspector выключена, формат флагов неизвестен или файл приложения изменился после старта процесса, подключение отклоняется. Это не мешает самому звонку; после обновления приложения может потребоваться его обычный перезапуск.
