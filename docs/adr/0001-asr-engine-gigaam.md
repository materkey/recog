# ADR-0001: Использование GigaAM для ASR

## Status
Accepted

## Context
Необходим движок для распознавания русской речи (ASR) в аудио/видео файлах. Основные требования:
- Высокое качество распознавания русского языка
- Возможность работы с длинными записями
- Локальный запуск без облачных API

## Decision
Использовать библиотеку **GigaAM** с моделью `v3_e2e_rnnt`.

### Причины выбора:
1. **Качество**: Одна из лучших open-source моделей для русского языка
2. **Архитектура**: RNN-T (end-to-end) — современный подход без отдельного языкового модели
3. **Интеграция**: Простой Python API через `gigaam.load_model()`
4. **Производительность**: ~2.4 chunks/sec на CPU (20 сек chunks)

### Альтернативы:
- **Whisper** — хорош, но хуже на русском
- **Vosk** — быстрее, но ниже качество
- **Cloud APIs** — требуют интернет и платные

## Implementation
```python
import gigaam
model = gigaam.load_model("v3_e2e_rnnt")
results = model.transcribe_longform(audio_path)
```

Для длинных записей используется chunked-режим:
- Chunk duration: 20 сек
- Overlap: 1 сек
- Дедупликация слов на границах chunks

## Consequences

### Positive:
- Высокое качество распознавания русской речи
- Не требует интернета
- Бесплатно

### Negative:
- Требует Python 3.10+
- Модель ~2 GB RAM
- Медленнее облачных решений на GPU
