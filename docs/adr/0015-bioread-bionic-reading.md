# ADR-0015: BioRead (Bionic Reading) в KTalk транскрипте

## Status
Proposed

## Context

Транскрипты встреч часто длинные, а в live-режиме текст появляется непрерывно. Пользователям с СДВГ и в целом при сканирующем чтении трудно удерживать внимание на строке: взгляд "соскальзывает", а смысл собирается с задержкой.

В текущей архитектуре KTalk Chrome extension (`kontur-diarize/ktalk-speaker-extension`) уже рендерит собственный transcript UI. Поэтому улучшение читаемости должно:
- Работать локально и без задержек (client-side)
- Быть настраиваемым под индивидуальную чувствительность
- Не требовать изменений backend pipeline и протоколов

## Decision

### 1) Место внедрения
Фича реализуется в KTalk Chrome extension и применяется только к рендеру текста транскрипта в UI. На backend и diarization pipeline изменений не требуется.

### 2) Управление и UX
Добавляется панель управления в тулбаре транскрипта:
- Toggle включения BioRead
- Слайдер Fixation Strength (доля слова, выделяемая жирным)
- Слайдер Saccade Contrast (прозрачность хвоста)

Горячая клавиша: `Alt+B` (не срабатывает при активном вводе в `input/textarea/[contenteditable]`).

Настройки сохраняются в `localStorage` (по аналогии с настройкой модели summary).

### 3) Алгоритм выделения
Трансформация применяется при рендере каждой строки:
- Токенизация на слова/цифры/пунктуацию.
- Слова длиной 1-2 символа: не изменяются или выделяется 1 символ.
- Числа/даты: не изменяются.
- Пунктуация: рендерится обычным начертанием.

Количество выделяемых символов:
`head_len = clamp(ceil(word_len * fixation), 1, floor(word_len * 0.6))`

### 4) Визуальная реализация
Слово рендерится как:
`<span class="bio-word"><span class="bio-head">...</span><span class="bio-tail">...</span></span>`

`bio-tail` управляется CSS custom properties:
- `--bioread-tail-opacity`
- `--bioread-tail-color`

Это позволяет менять "контраст саккады" без пересчета DOM.

## Implementation Plan (scope)

| Шаг | Файл | Изменение |
|-----|------|-----------|
| 1 | `kontur-diarize/ktalk-speaker-extension/src/state.js` | Добавить состояние BioRead |
| 2 | `kontur-diarize/ktalk-speaker-extension/src/ui.js` | Добавить UI-контролы, hotkey, CSS |
| 3 | `kontur-diarize/ktalk-speaker-extension/src/utils.js` или новый `bioread.js` | Трансформация текста в BioRead |
| 4 | `kontur-diarize/ktalk-speaker-extension/src/ui.js` | Применить трансформацию в `updateTranscriptUI()` |

## Consequences

### Positive
- Повышение скорости чтения и устойчивости внимания
- Настраиваемость под индивидуальные потребности
- Нулевая нагрузка на backend и протоколы

### Negative
- Рост количества DOM-узлов (каждое слово разбивается на 2 span)
- Дополнительные UI-контролы в тулбаре
- Требуется аккуратное экранирование HTML при рендере текста

## Alternatives Considered

1) Серверная/пайплайновая трансформация транскрипта
   - Приводит к задержкам и усложняет протокол, не подходит для live.

2) Только `font-weight` без снижения контраста хвоста
   - Эффект фиксации слабее, хуже управляется сенсорной нагрузкой.

3) Только выбор специализированного шрифта
   - Улучшает читабельность, но не решает проблему "фиксации".
